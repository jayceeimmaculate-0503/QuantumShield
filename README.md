# 🛡️ QuantumShield

QuantumShield is an advanced security web application built with Flask that integrates post-quantum cryptography, file encryption mechanisms, and threat intelligence modules to protect sensitive data against emerging computational threats.

## 🚀 Key Features

* **Post-Quantum Cryptography**: Implements state-of-the-art cryptographic standards (such as ML-KEM-768) to secure data communication and storage against quantum-based attacks.
* **Secure File Encryption**: Robust file encryption and decryption workflows powered by robust cryptographic algorithms (e.g., AES-256-GCM, SHA-256 key derivation).
* **Phishing URL Detection**: Machine learning/pattern-matching module designed to detect malicious and phishing URLs.
* **Interactive Flask Dashboard**: Clean, user-friendly web interface for users to manage encryption tasks, view security metrics, and interact with the platform.
* **SQLite Database Integration**: Secure user authentication, session management, and transaction logging.

---

## 🛠️ Tech Stack

* **Backend**: Python, Flask, Gunicorn
* **Cryptography**: Open Quantum Safe library (`liboqs`), Python Cryptography package
* **Machine Learning / Data**: scikit-learn
* **Database**: SQLite
* **Frontend**: HTML5, CSS3, JavaScript (Dashboard templates)
